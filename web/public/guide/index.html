CLine46 非公式セットアップガイド

トラックボールジェスチャーや慣性スクロールなど様々な新機能を 使ってみたい方へのガイドです。

面倒なのはファームウェアの入れ替えだけです。 それさえ済めば、カスタマイズは Bluetooth でつないだブラウザ上の マウス操作だけ。基本のキー設定は DYA Studio、 ジェスチャー機能はころころKit。

ファームウェアのダウンロード： ころころKit トップページのダウンロード欄 にあります。
2026年8月22日 更新: ころころKit で変更した内容が電源を入れ直すと 初期値に戻る不具合を修正しました。8月18日版をお使いの方は書き換えをおすすめします。
ここで配布しているファームウェアは、CLine46 の公式ファームウェアに 最新機能を追加したベータ版にあたるものです。 手元の実機で動作を確認はしていますが、もしも挙動がおかしいときは 公式ファームウェア に戻してください。設定した内容はそのまま残り、消えません。

ファームウェアの書き込み方

CLine46 は左右それぞれにコントローラ（Seeed XIAO nRF52840）が入っていて、 ファームウェアも左右別々のファイルを書き込みます。手順はどちらも同じです。

  1. キーボードの片側を USB ケーブルで PC と接続します
  2. コントローラの小さな Reset スイッチをダブルクリックします。 場所は takamaru さんの解説ページ が参考になります
  3. 成功すると PC に USB ストレージ（XIAO-SENSE）として 認識されます
  4. そこへ .uf2 ファイルをコピーします。 右側には CLine46_R-…、左側には CLine46_L-… の ファイルです（ファイルは ダウンロード欄 から入手できます）
  5. コピーが終わるとドライブが自動的に消えて、キーボードが再起動します。 これで完了です（ドライブが消えるのは正常な動作です）
うまくいかないとき
  • ダブルクリックの速さを変えて何度か試してください（速すぎ・遅すぎで入らないことがあります）
  • ケーブルが充電専用（データ線なし）だとストレージとして認識されません。別のケーブルを試してください
  • 書き込みに失敗しても壊れることはまずありません。もう一度 Reset ダブルクリックからやり直せます

同じファイルをもう一度書き込むと一瞬で終わることがあります。これは書き込み装置が 「内容が同じ部分を飛ばす」ためで、失敗ではありません。

キーマップのカスタマイズ — DYA Studio

キーの割り当て・マクロ・トラックボールの設定は DYA Studio （cormoran さん作）で、再ビルドなしにブラウザから変更できます。

  1. キーボード側で studio_unlock キーを押します。 標準キーマップでは SCROLL レイヤー（レイヤー3）にあります
  2. DYA Studio を開き、USB か Bluetooth で接続します
Bluetooth でつながらないとき： ZMK は設定用の通信を「キー入力の出力先」と同じ経路にしか返しません。 USB ケーブルを抜いてから接続するか、DYA Studio の接続設定で 出力優先度を Bluetooth に切り替えてください。また、DYA Studio・ZMK Studio・ ころころKit のうち同時に接続できるのは1つだけです。

ジェスチャーの設定 — ころころKit

トラックボールジェスチャー（レイヤーキー + ボールの上下左右で発動する操作）の 割り当ては ころころKit で変更できます。 おすすめ初期設定を選ぶだけでも使い始められます。 このツールも studio_unlock キーを押して接続してください。

配布ファームウェアに入っているもの

ころころKit のページで配布しているファームウェアは、 2026年8月18日時点の CLine46 最新ファームウェアに次の機能を追加した詰め合わせです。

ジェスチャー機能（ころころKit で設定）

  • トラックボールジェスチャーの組み込み。判定は実機で調整済みで、誤爆は稀です
  • レイヤーを11個（0〜10）に拡張し、7〜10 を GESTURE1〜4 と命名。初期状態でレイヤー7〜10 に16個のジェスチャーが設定され、レイヤー4〜10 の範囲で最大6グループ・24個まで拡張できます

慣性スクロール（標準版のみ）

  • スクロールレイヤーでボールをフリックして離すと、スクロールが滑らかに減衰しながら続きます（mjmjm0101 さんの zmk-input-processor-scroll-inertia）
  • 好みが分かれる機能なので、慣性なし版も並べて配布しています。ファイル名に no-inertia が入っているものがそれです

JIS/US 配列の切り替え

  • 接続先の PC が JIS 配列設定のときの記号ずれを、キーボード側で吸収できます（kot149 さんの zmk-layout-shift）
  • 使い方: DYA Studio かころころKit で Toggle Layout Shift をキーやジェスチャーに割り当て、押して切り替えます。起動時は OFF（従来どおり）です

そのほかの改善

  • スクロール量と軸スナップを DYA Studio の「トラックボール」タブから調整できます（再ビルド不要）
  • Runtime Macro（DYA Studio の「マクロ&コンボ」で作るマクロ）をキーに割り当てられます
  • 設定ツール接続中の Bluetooth 応答を改善（3110 さんの知見）。DYA Studio やころころKit の操作の引っかかりが減ります

困ったとき

  • 設定ツールにつながらない — ツールをすべて閉じて1つだけ開き直す。駄目ならキーボードの電源を入れ直す
  • 書き込み後に動作がおかしい — もう一度同じファームウェアを書き込み直す。それでも駄目なら前の版に戻す
  • その他お気づきの点は @tu_no_tu までお知らせください
